# 100 Days of MLOps

Daily hands-on MLOps labs from KodeKloud. Each folder documents not just *what* was done, but the **reasoning process** — the decision tree an ML engineer would use, common pitfalls in ML infrastructure, and how concepts transfer across tools and platforms.

## How I approach these

Each task starts with identifying the real-world ML infrastructure problem, understanding why the specific tool/approach exists (not just how to use it), then solving it with reasoning attached to every step. I document common mistakes and a transfer exercise to test whether the concept generalises to different tools and scales.
